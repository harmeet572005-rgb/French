BEBU BOYFRIEND'S DAY WEBSITE

Files:
- index.html
- style.css
- script.js
- song.mp3

IMPORTANT:
1. Keep song.mp3 in the same folder as index.html.
2. If you are publishing on GitHub Pages, upload all four files.
3. The website starts the music after the user clicks "Open Your Surprise", because modern browsers generally block sound autoplay before user interaction.
4. The uploaded MP3 is included exactly as supplied.
5. This package uses placeholder photo1.jpeg through photo11.jpeg references. Replace them with your own photos, keeping those filenames.
